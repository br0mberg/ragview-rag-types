# Как предложить изменение

Для исправления кода добавьте тест, который воспроизводит проблему, и запустите:

```bash
./mvnw --batch-mode --no-transfer-progress test
python3 -m unittest discover -s tools -p 'test_*.py'
```

Новый эксперимент храните в отдельном каталоге `results/runs/<run-id>`. Не
редактируйте итоговые CSV вручную. Вместе с результатом приложите конфигурацию,
версии моделей, окружение и `MANIFEST.sha256`.

Не добавляйте полный текст правового корпуса, raw HTML, веса моделей, секреты и
локальные build-артефакты. Для ошибки воспроизводимости укажите команду,
окружение, ожидаемый результат и фактический вывод.
